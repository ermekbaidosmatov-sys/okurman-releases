# Окурман

«Окурман» — мугалимдер, ата-энелер жана окуучулар үчүн окуу тиркемеси (Android).

## Жүктөп алуу
Акыркы версияны **[Releases](../../releases/latest)** бөлүмүнөн `.apk` файл катары жүктөп алыңыз.
Тиркеме жаңы версия чыкканда өзү билдирип, бир басуу менен жаңыртат.
